# muNoteServer

## 개요
- 크로스플랫폼 개인용 노트 애플리케이션 muNote의 API 서버.   
- API를 통해 폰, 태블릿, 데스크탑 환경 등에서 muNote를 동기화하는 것에 목적.   
- Joplin, Notion, Memo.app 등 기존 솔루션을 즐겨 사용하다가 자체적인 노트 솔루션 제작에 도전해보고 싶어서 시작.   

## 사용법
1. 현재 깃허브에서 프로젝트를 내려받아서 직접 빌드하여 실행하거나 도커에서 배포된 서버 이미지를 컨테이너 실행.   
2. 추후 무료 배포될 muNote의 웹버전, 폰버전, 태블릿버전, PC버전 클라이언트를 다운로드 받아서 실행시킨 후 위에서 실행한 서버 아이피를 입력하여 접속.   
3. 이후 단순한 메모용도로 편하게 사용.   

## 목표 스펙
- DOTNET 8.0의 ASP CORE 기반 웹 애플리케이션.   
- SQLite 기반 로컬 데이터 베이스 사용.   
- 깃허브에 모든 소스 공개.   
- RESTful 기준을 만족하는 웹 API 서버.   
- DTO, DDD 기반 서버 로직 구성.   
- 클라이언트는 Flutter 혹은 Uno 기반 개발.      


## 기본 작업 완료 후 추가 예정 스펙   
- 플레인텍스트 외의 마크다운, 머메이드, 코드, 다이어그램, 마인드맵 등등 다른 기능 노트 추가.   
- 서버에 관리툴, 지표툴, API도큐먼트, 스웨거 등 부가 솔루션 추가.   
- 워크스페이스에 사용자 퍼미션 기능 추가하여 팀용 확장.   
- 워크스페이스 내부 검색 기능 추가.
